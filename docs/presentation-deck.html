What Happens Today (Static Apps)

  • Generic advice: "Study more physics for 2 hours today."
  • Schedule debt: Missing yesterday adds tasks to an already impossible queue.
  • False precision: Displays arbitrary 87% mastery scores derived from small samples.
  • No execution: Conversational chat bots only offer text, not action.

PathPilot's Dynamic Solution

  • Diagnoses exact micro-skills: (e.g. Vector Components in Q2).
  • Adapts to actual minutes: Fits study tasks into a realistic 30-minute block.
  • Honest evidence: Reports "1 of 3 correct" with explicit sample caveats.
  • Action-taking agent: Re-plans and saves directly to the database.

Genuine Agent Action

Natural-Language Re-Planning in Action

Student Request:

"I only have 30 minutes today."

Backend Tool Execution

  • Calls allowlisted tool: replan(available_minutes=30)
  • Optimistic lock: validates expected_version: 1
  • Generates Plan Version 2 atomically in SQLite WAL
  • Allocates 30 minutes: 10m learn + 15m practice + 5m review

Explicit Task Deferral

  • Tasks exceeding 30 minutes moved to deferred_tasks
  • No tasks are silently dropped or ignored
  • Task checkboxes preserve completion status across versions
  • Checking a task does not inflate assessment score

Architecture

Deterministic Code vs. AI Agent Roles

Deterministic Engine (100% Reliable)

  • Immediate server-side answer grading
  • Calculates exact minute budgets ($10 + 15 + 5 = 30$)
  • Session isolation & HttpOnly cookie hashing
  • Idempotency ledger prevents duplicate answer commits
  • Optimistic plan version conflict rejection (409 Conflict)

AI Mentor Layer (Constrained & Honest)

  • Understands natural language requests
  • Restricted to 5 allowlisted service functions
  • Zero SQL, zero arbitrary code execution permissions
  • Offline Fallback: If LLM API is unavailable, truthfully reports: Mode: Deterministic Fallback
